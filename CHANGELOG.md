# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). This project does not use formal version numbers — changes are grouped under **Unreleased** until a release process is introduced.

## [Unreleased]

### Added

- Core photo editing tool: drag-and-drop background removal onto a uniform white canvas (studio mode), with single and batch upload.
- Atmosphere mode: AI-generated lifestyle/scene photos (e.g. a model wearing the shoe), with an optional free-text prompt to steer the scene.
- Per-photo metadata: model number, SKU, price, size range, color, and logo selection, with the option to burn model number/SKU/size/color directly into the saved image for quick one-off sharing.
- Inline logo management: upload and reuse logos without leaving the creation flow.
- Photo gallery with search/filter and multi-select for catalog building.
- PDF catalog builder with four templates (classic grid, minimal list, single-product feature, branded two-column), correctly rendering Hebrew/RTL text.
- ZIP + CSV export for batches of processed photos.
- Categorized navigation hub (`/start`) and a welcome/landing page (`/`).
- Dark "studio" design system: brown/black/gray palette, Heebo + Frank Ruhl Libre typography, and `motion`-driven press/hover feedback, page transitions, and scroll-triggered reveals across the app.
- Repository docs: [README](README.md) setup instructions, [CONTRIBUTING](CONTRIBUTING.md), [CODE_OF_CONDUCT](CODE_OF_CONDUCT.md), [SECURITY](SECURITY.md), and [LICENSE](LICENSE).
